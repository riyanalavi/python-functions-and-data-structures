# Python Functions & Data Structures Projects

Two beginner-friendly Python projects built to practice functions, loops, conditionals, lists, and dictionaries.

## Projects

### Student Marks Analyzer

Enter students’ names and marks for multiple subjects. The program calculates each student’s average and grade, the class average, and the top student.

### To-Do List App

A command-line app for adding, viewing, completing, and deleting tasks. Tasks are stored in memory and reset when the program closes.

## Requirements

- Python 3
- No external libraries required

## How to Run

Open a terminal in the project folder and run either program:

```bash
python student_marks_analyzer.py
```

```bash
python todo_list.py
```

On some systems, use `python3` instead of `python`.
